# Student Planner

A beginner-friendly student planner built with HTML, CSS, and JavaScript. Organize study tasks, assignments, exams, and personal reminders in one place.

## Features

- Add, edit, and delete tasks
- Add a subject, due date, priority, and task type
- Mark tasks as completed
- Search tasks by name, subject, or type
- Filter between all, pending, and completed tasks
- View total, pending, and completed task counts
- Saves tasks in browser local storage
- Responsive layout for mobile and desktop

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## Run locally

No installation or backend is required.

1. Download or clone this repository.
2. Open the `student-planner` folder.
3. Double-click `index.html` to open it in your browser.

For a better development experience, open the folder in Visual Studio Code and use the **Live Server** extension.

## Save to GitHub

Create a new GitHub repository named `student-planner`, then run these commands inside this project folder:

```bash
git init
git add .
git commit -m "Initial student planner project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/student-planner.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Data note

Tasks are stored in the browser's local storage on the device and browser where you use the app. They are not automatically synced to another device. Clearing browser data may remove saved tasks.
